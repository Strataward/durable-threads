# Code of Conduct

## Our promise

We want this project to remain useful, safe, and welcoming. Contributors must
act with respect and good faith.

## Expected behavior

- Use clear and respectful language.
- Focus on the technical issue, not the person.
- Accept corrections without hostility.
- Protect private source code, credentials, and personal data.
- Report safety and security concerns through the process in `SECURITY.md`.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberate exposure of credentials or private project data.
- Malicious code, supply-chain abuse, or unsafe automation.

Project maintainers may remove content or restrict participation when needed to
protect the project and its users.

## Enforcement

Report conduct concerns to the repository maintainers through a private GitHub
contact method. Do not open a public issue for a sensitive report.
