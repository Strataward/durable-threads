# Governance

Durable Threads is maintained by the repository owner during the alpha
period.

The maintainer may accept, request changes to, or reject a contribution. The
maintainer may change this process as the project grows.

Technical decisions must include a problem statement, the chosen trade-off,
and evidence from tests or real use. Changes that increase external access,
secret handling, or automatic mutation need an explicit security review.

The project will seek additional maintainers after it has a stable release and
regular external contributions.
